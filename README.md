# RoadSafe 
RoadSafe is an intelligent AI-based traffic surveillance system designed to improve road safety and automate the detection of traffic violations. The system leverages state-of-the-art computer vision models to monitor various traffic scenarios in real time and enforce rule compliance efficiently.

🚦 Key Features
Helmet Detection & Occupancy Analysis in three-wheelers using YOLOv5

Lane Detection, Seatbelt Monitoring, Mobile Phone Usage, and Vehicle Classification with YOLOv8

Emergency Vehicle Recognition and Number Plate Detection

Automatic Number Plate Recognition (ANPR) via PaddleOCR for tracking violations

Video Upscaling using ESRGAN for enhanced detection accuracy in low-resolution video feeds

Modular & Scalable Architecture suitable for integration with smart city infrastructure
